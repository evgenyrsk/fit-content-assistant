# Style profile v1 — comparative evaluation

The owner-provided product brief, explicit delegation and direct correction of generated copy were converted into `evgeny-style@1.1.0`. No interview transcript was invented. Four preferred/rejected pairs cover Threads, Telegram and Reels; each pair includes a working explanation rather than a causal claim about performance.

Automated checks confirm that all four preferred variants avoid the profile's prohibited phrases, while rejected variants trigger at least one explicit rule. The added Threads pair distinguishes a direct, friend-like explanation from theatrical setup and an aphoristic ending. This is a regression set for voice consistency, not proof that a wording will perform better.

Run `npm run eval:style` to reproduce the comparison. Real publication metrics remain separate and may only produce qualified hypotheses from saves, shares and comments.
