# Политика законного доступа к источникам

## Принцип

Forme получает и хранит полный текст только когда источник явно разрешает автоматическое получение и повторное использование. Наличие DOI, PMID или страницы статьи не означает право сохранять её полный текст.

## Разрешённые автоматические каналы

- PubMed и Crossref — библиографические метаданные и discovery.
- PubMed EFetch — опубликованные аннотации и record integrity.
- PMC Open Access через официальный BioC API — полный текст только после проверки лицензии.
- В будущем: другие официальные Open Access API с машинно проверяемыми rights metadata.
- Пользовательская загрузка — только для материалов, к которым владелец имеет законный доступ; права и область использования сохраняются рядом с документом.

Текущий PMC adapter принимает `CC BY`, `CC BY-SA`, `CC0`, public domain и явно сформулированную Creative Commons Attribution License. `NC`, `ND`, неизвестная или отсутствующая лицензия блокируют автоматическое сохранение до отдельного правового решения.

## Запрещённые каналы

Forme не интегрирует сервисы, которые обходят paywall, авторизацию, технические ограничения или условия издателя. Такие URL не становятся fallback-источником и не попадают в конфигурацию продукта.

## Provenance и полнота

Для разрешённого PMC-текста сохраняются PMCID, PMID, лицензия, источник доступа, section type, offset и content hash. Full-text gate открывается только при наличии как минимум Methods и Results. Это проверка технической пригодности текста, а не научного качества работы.

Официальный PMC BioC API предоставляет статьи из Open Access subset и manuscript collection, но не все записи PMC. PMC отдельно подчёркивает, что права повторного использования различаются, поэтому Forme применяет дополнительный allowlist лицензий.
