# Дизайн-система Forme

## Характер

Современный editorial-инструмент на стыке научного журнала и премиального продукта для автора. Спокойный, точный, собранный — без стерильной «медицинской» эстетики и без агрессивного фитнес-инфобизнеса.

## Визуальные принципы

- Сильная типографическая иерархия вместо декоративного шума.
- Тёмный лесной цвет как поверхность фокуса.
- Тёплый бумажный фон для долгой комфортной работы.
- Кислотно-лаймовый акцент только для действия и активного состояния.
- Графические мотивы: сетки, орбиты, линии сигнала и evidence-маркеры.
- Крупные радиусы, тонкие границы, глубокие мягкие тени.
- Один экран — один главный следующий шаг.

## Типографика

Manrope — основной интерфейсный шрифт. Крупные заголовки плотные, с отрицательным трекингом. Служебные подписи короткие, прописные, с увеличенным межбуквенным интервалом.

## Состояния доказательств

- High confidence: forest/green.
- Moderate confidence: amber.
- Low/insufficient: rose.
- Processing: cobalt.

Цвет никогда не является единственным носителем смысла: рядом всегда есть текстовый статус.

## Motion

Анимация короткая и функциональная: появление результата, изменение evidence-сигнала, переход между форматами. Учитывается `prefers-reduced-motion`.

## Темы

Светлая и тёмная темы являются равноправными вариантами интерфейса. Выбор сохраняется на устройстве пользователя. В тёмной теме поверхности строятся на нескольких уровнях лесного чёрного, а лаймовый акцент остаётся цветом действия — фон не инвертируется механически.

## Пространство

Базовая шкала отступов: `6 / 10 / 14 / 20 / 28 / 40 px`. Внутренние отступы карточек, расстояния между секциями и плотность списков используют эту шкалу. На мобильных устройствах крупные значения уменьшаются, но визуальная иерархия сохраняется.

## Иконки

Интерфейс использует Lucide SVG с единым контурным характером. Базовый stroke — `1.8`, рабочие размеры — `12 / 14 / 16 / 18 px`; увеличенный контейнер используется только для главных действий. Unicode-символы и emoji не используются как иконки: их форма зависит от шрифта и платформы. Иконка не заменяет текстовый статус, а icon-only кнопка всегда получает доступную подпись.

## Навигация

Каждый пункт основного меню открывает отдельное рабочее представление и получает явное активное состояние. Смена раздела не сбрасывает тему; URL hash отражает текущий раздел и позволяет вернуться к нему после обновления страницы.
