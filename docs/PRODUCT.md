# Продукт

## Для кого

Для автора фитнес-контента, которому нужна скорость без потери научной аккуратности.

## Основная работа пользователя

Задать вопрос или исходную идею и получить:

1. точную формулировку проверяемого вопроса;
2. найденные источники отдельно от их оценки;
3. набор claims с уровнем уверенности и ограничениями;
4. практический вывод понятным языком;
5. адаптированный материал под выбранную платформу;
6. фактчек и трассировку до источников.

## Неизменяемые принципы

- Evidence before storytelling.
- Claim — основной объект знания.
- Неопределённость — допустимый результат.
- Личный опыт может быть сюжетом, но не доказательством.
- Система предлагает исправить неверный исходный угол, а не подтверждает его.

## MVP

MVP должен закрывать один вертикальный сценарий полностью:

`вопрос → поиск → оценка → claims → сохранение → Reels → фактчек`

Не входят в первый рабочий релиз: командная работа, сложная аналитика публикаций, автоматический импорт всех PDF, мобильное приложение и генерация сложной графики.

## Критерий успеха

Автор может подготовить научно обоснованный черновик Reels быстрее, чем вручную, и в любой момент увидеть, на каких тезисах и источниках он построен.
