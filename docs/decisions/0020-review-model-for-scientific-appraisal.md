# ADR 0020: review-модель для научной оценки

## Статус

Принято.

## Контекст

Экономная research-модель хорошо подходит для расширения поискового запроса и discovery, но реальный source assessment может не пройти большой строгий JSON-контракт. Показатель доверия нельзя рассчитывать из неполного или непроверяемого ответа.

## Решение

- Research plan и discovery остаются на provider-agnostic `research` route.
- Source assessment и body-of-evidence assessment используют provider-agnostic `review` route.
- Для source/body/claim appraisal действует ограниченный 120-секундный timeout; остальные маршруты сохраняют короткий timeout.
- Review-модель не выставляет процент. Она возвращает только структурированные суждения с provenance.
- Индекс 0–100 по-прежнему рассчитывается детерминированным кодом и ограничивается evidence gate.
- Любой невалидный ответ закрывает gate; автоматического fallback-score нет.

## Последствия

Научная оценка может стоить немного дороже discovery, зато получает отдельную модель, выбранную для строгой проверки. Провайдера и конкретную модель можно менять конфигурацией без изменения домена. Человеческое подтверждение и калибровка методологии остаются обязательными.
