# ADR-0026: Карточка выборки с трассировкой

- Статус: принято
- Дата: 2026-09-07
- Владельцы: Forme

## Контекст

Короткое русское саммари помогает быстро прочитать источник, но без популяции, численности и групп легко создать впечатление более широкой применимости, чем допускает исследование. Эти данные нельзя достраивать из названия, общих итогов или частично описанного метода.

## Решение

`readerBrief` хранит отдельную карточку из трёх полей: участники, численность и группы. Каждое поле содержит текст, флаг `reported` и provenance ids. При `reported=true` требуется хотя бы один реально переданный passage id. При отсутствии сведения единственное допустимое значение — «Не указано в доступном тексте.», `reported=false` и пустой список ссылок. Карточка сохраняется в D1 рядом с reader brief; прежние записи остаются читаемыми и отображают эти поля как неуказанные.

## Последствия

- Пользователь видит применимость и масштаб работы до чтения полного текста.
- Модель не может превратить отсутствие данных в правдоподобную деталь.
- Карточка — навигационный слой, не новый evidence gate и не оценка качества исследования.

## Проверка

Строгий контракт отклоняет сообщённую деталь без provenance и «неуказанную» деталь с фиктивной ссылкой. Execution-тест отклоняет неизвестный passage id в карточке.
