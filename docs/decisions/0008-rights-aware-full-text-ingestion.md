# ADR-0008: Rights-aware импорт полного текста

- Статус: принято
- Дата: 2026-08-27
- Владельцы: Forme
- Заменяет: —

## Контекст

Source assessment требует методов и результатов, которых обычно нет в аннотации. Многие статьи доступны только по подписке, а наличие технически доступной копии не означает право автоматически скачивать, хранить и обрабатывать её в продукте.

## Критерии решения

- официальный автоматизированный API;
- явные machine-readable права повторного использования;
- точная section-level provenance;
- отсутствие обхода paywall и авторизации;
- возможность расширять список разрешённых adapters независимо от evidence logic.

## Рассмотренные варианты

1. **Загружать полный текст с любого доступного URL.** Максимальное покрытие, но неприемлемый правовой и операционный риск.
2. **Хранить только аннотации.** Безопасно, но блокирует полноценный appraisal.
3. **Подключать rights-aware Open Access adapters.** Меньше покрытие, зато происхождение, лицензия и границы использования проверяемы.

## Решение

Выбран третий вариант. Первый adapter использует официальный PMC Open Access BioC API в batch-режиме. Он принимает только allowlisted лицензии без NC/ND-ограничений, требует PMID/PMCID, Methods и Results, сохраняет абзацы с section type и offset и повышает `content_level` до `full_text` без потери предыдущих abstract chunks.

Метаданные документа хранятся отдельно в `source_documents`; повторный abstract import не может понизить уже подтверждённый full-text уровень. Более строгий record status из PubMed также не перезаписывается значением `active` из PMC.

## Последствия и риски

Forme получает реальные assessment-grade passages без зависимости от LLM и без обхода доступа. Покрытие ниже, чем у неразрешённых агрегаторов. Лицензии могут изменяться или интерпретироваться неоднозначно, поэтому неизвестные и ограничительные варианты fail closed, а запись перепроверяется по сроку.

## Проверка и пересмотр

Adapter tests проверяют batch-загрузку, лицензионный allowlist, обязательные секции и provenance offsets. Политика пересматривается перед коммерческим запуском, при добавлении нового типа лицензии или нового full-text provider.
