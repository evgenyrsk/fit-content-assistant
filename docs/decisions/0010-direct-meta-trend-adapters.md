# ADR-0010: Прямые Meta-сигналы через серверные адаптеры

- Статус: принято
- Дата: 2026-08-28
- Владельцы: Forme
- Заменяет: —

## Контекст

Trend Scout должен находить актуальные темы непосредственно в Threads и Instagram, но не смешивать популярность публикации с научной достоверностью. Проект пока однопользовательский, поэтому полноценный публичный OAuth и хранение токенов многих пользователей добавили бы лишнюю поверхность риска.

## Критерии решения

- только официальные Meta API и разрешения владельца аккаунтов;
- токены недоступны браузеру, логам и репозиторию;
- отсутствие или истечение токена честно отображается как недоступный источник;
- социальный сигнал никогда не становится evidence или claim;
- провайдер можно заменить без изменения domain и application слоёв.

## Рассмотренные варианты

1. **Скрапинг публичных страниц.** Отклонён из-за нестабильности, отсутствия надёжного контракта и риска нарушения условий платформ.
2. **Публичный OAuth для любого пользователя.** Отложен до появления многопользовательского сценария.
3. **Серверные адаптеры с long-lived токенами владельца.** Минимальная безопасная схема для личного проекта.

## Решение

Threads использует официальный `keyword_search`, Instagram — официальный поиск хештега и `recent_media`. Оба адаптера реализуют общий application-port `TrendProvider`. Токены и версии API задаются только как секреты production runtime; они не сохраняются в D1, client state или исходном коде.

Threads и Instagram ранжируются только как сигналы актуальности. Instagram hashtag search не называется глобальным трендом: это выборка свежих публикаций по заданному хештегу. Любая тема после выбора проходит отдельный научный research pipeline.

## Последствия и риски

В однопользовательском режиме подключение требует один раз выдать разрешения и безопасно внести long-lived токены. Истечение или отзыв токена делает источник недоступным, не подменяя его demo-данными. Автоматическое обновление токенов и публичный OAuth потребуют отдельного зашифрованного credential store и нового ADR.

## Проверка и пересмотр

Contract tests проверяют mapping, freshness и двухшаговый Instagram hashtag flow. Решение пересматривается при появлении нескольких пользователей, публикации контента через Meta API или официального trending endpoint с более сильным сигналом роста.
