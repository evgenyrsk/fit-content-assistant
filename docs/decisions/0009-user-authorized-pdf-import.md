# ADR-0009: Импорт пользовательских PDF с подтверждением доступа

- Статус: принято
- Дата: 2026-08-27
- Владельцы: Forme
- Заменяет: —

## Контекст

Не для каждой подходящей статьи существует автоматизированный Open Access endpoint. Владелец проекта может законно получить PDF через автора, покупку, подписку или институциональный доступ и должен иметь возможность добавить его без ослабления evidence gates.

## Критерии решения

- исходный файл остаётся приватным;
- основание доступа и подтверждение владельца проверяемы;
- повторная загрузка не создаёт дубликаты;
- неструктурированный или нечитаемый PDF не становится assessment-grade evidence;
- bytes, реляционные метаданные и retrieval chunks имеют разные хранилища и ответственности.

## Решение

PDF до 15 МБ и 100 страниц принимается только после явного rights attestation. SHA-256 определяет канонический source id и object key. Исходные bytes сохраняются в private R2, а D1 хранит `manual_source_imports`, библиографические данные, intake decision, audit event и постраничные chunks.

Serverless PDF extractor работает с отключённым eval, ограничивает размер изображений, число страниц и время обработки. Полный текст считается доступным для retrieval, но assessment-grade provenance требует одновременно распознанных Methods и Results. Иначе запись получает `structure_review_required`; PDF без достаточного текстового слоя получает `text_unavailable` и не допускается в корпус.

## Последствия и риски

Система покрывает статьи, законно полученные владельцем, не выполняя внешний обход доступа. Автоматическое извлечение не является OCR и может ошибаться на сканах, сложной вёрстке и нестандартных заголовках. DOI, PMID, record status и структура требуют последующей проверки.

## Проверка и пересмотр

Тесты покрывают page-level extraction, дедупликацию, rights provenance, Methods/Results gate и компенсационное удаление R2 object при ошибке D1. Перед расширением лимитов требуется повторная оценка Worker memory/time budgets и форматов недоверенных PDF.
