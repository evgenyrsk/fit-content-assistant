# ADR-0001: Claim-first hybrid RAG

- Статус: принято
- Дата: 2026-08-26

## Контекст

База будет расти за счёт научных источников, проверенных выводов и созданного контента. Одного полнотекстового поиска недостаточно для смысловых запросов, но одна vector DB не хранит надёжно версии, статусы и доказательную трассировку.

## Решение

Использовать D1/SQLite как каноническую базу и два раздельных retrieval-индекса: source chunks и approved claim versions. Объединять метаданные, lexical search, embeddings и reranking. Content Engine читает утверждённые claims, а не произвольные chunks.

## Последствия

- Истина и retrieval разделены; индекс можно перестраивать.
- Версионирование и аудит остаются прозрачными.
- Реализация сложнее простого «chat with PDFs», но существенно снижает риск неподдержанных выводов.
- Для MVP подходит управляемый vector store; инфраструктуру можно заменить без изменения доменной модели.
