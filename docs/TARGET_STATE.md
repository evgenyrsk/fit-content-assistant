# Целевое состояние Forme

## Продуктовый результат

Forme проводит один вопрос через воспроизводимый контур:

`вопрос или live-тема → план исследования → поиск → оценка результатов → body certainty → versioned claims → retrieval → платформенный контент → независимый фактчек → история`

Найденный источник никогда не становится публичным тезисом автоматически. Отсутствие надёжного ответа считается полноценным результатом.

## Режим автономной разработки

Принятые пользователем настройки:

- provider-agnostic LLM layer;
- экономный профиль до появления измеримого бюджета;
- style profile `evgeny-style@1.0.0` утверждён по owner brief и автономному делегированию; новые примеры будут основанием для v2;
- Trend Scout входит в текущий этап;
- внешние расходы и автоматическая публикация не включаются без отдельного решения.

До подключения ключей разрабатываются и проверяются общие контракты, адаптеры, fixtures и deterministic gates. При появлении ключа меняется composition root, а не доменная логика.

Уже без ключа доступны: раздельный lexical search по claims/passages, maintenance queue, session-based PubMed revalidation, ручной traceable content workflow, version history, fact-check, календарь, банк тем, личные `narrative_only` заметки, архив публикаций и CSV-метрики.

## Критерии готовности

### Research

- PubMed и Crossref возвращают реальные source candidates с DOI/PMID и временем обнаружения;
- запрос и кандидаты сохраняются в D1;
- частичная недоступность провайдера видима и не подменяется модельным текстом;
- поиск включает не только подтверждающие результаты.

### Evidence и Knowledge

- study appraisal и body certainty разделены;
- каждое измерение имеет rationale и provenance;
- claim версионируется и не перезаписывается;
- публикация заблокирована при incomplete evidence, просрочке или отсутствии review;
- retrieval index можно перестроить без изменения канонической базы.

### Content

- Reels, Telegram, Threads и карусель имеют разные versioned playbooks;
- каждый фактический fragment связан с claim version;
- voice edit не может повысить уверенность или удалить обязательную оговорку;
- unsupported factual claim rate на blocking eval равен нулю.
- ручной материал не может перейти в календарь без свежей claim-трассировки и human fact-check;
- публикация сохраняет URL, а performance snapshots не меняют научную уверенность.

### Trends

- каждый сигнал показывает источник, observed time и тип сигнала;
- Google Trends/News обозначаются как public proxy, PubMed Research Pulse — как научная свежесть, а не social virality;
- закрытые платформенные данные появляются только через разрешённые API;
- популярная тема отклоняется, если она не подходит аудитории или не исследуема.

## Точки участия пользователя

1. Добавить ключ одного или нескольких LLM-провайдеров и при желании месячный лимит.
2. Позже пройти challenge-интервью для style profile v1.
3. Подключить профессиональные Meta-аккаунты, если нужны прямые сигналы Threads/Instagram.
4. Утвердить научную методологию после калибровки; до этого автоматический approval выключен.
